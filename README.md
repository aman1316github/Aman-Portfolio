# Aman Choudhary Portfolio

Premium minimalist portfolio built with React, Vite, and Tailwind CSS.

## Setup

1. Place the developer image at `public/Mine image.jpeg`
2. Place the resume PDF at `public/Resume_Aman Updated.pdf`
3. Install dependencies:

```bash
npm install
```

4. Run the development server:

```bash
npm run dev
```

## Notes

- Uses a dark luxury theme with subtle grain texture.
- Includes sticky glassmorphism navbar, tech bento grid, work timeline, selected projects, and contact form.
- Resume and image are referenced from the `public/` folder.
